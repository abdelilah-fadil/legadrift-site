Sécurité et données

Votre code source est un actif sensible. LegaDrift le traite comme tel.

Ce que LegaDrift fait de votre code, de vos données et de vos accès, dit précisément, pour que votre RSSI puisse l'examiner.

Le code source

Il reste où vous le décidez

Le lieu d'exécution est votre choix

Sur votre infrastructure, dans votre compte cloud ou chez LegaDrift. Installé chez vous, LegaDrift ne renvoie rien vers LegaDrift.

Rien ne part sans votre accord

Aucun code ne part vers un modèle d'IA situé hors de votre périmètre sans un acte positif de votre part, et cet acte est tracé.

Ce qui part au modèle reste visible

Vos équipes habilitées peuvent consulter ce qui a été envoyé au modèle d'IA, projet par projet.

Le code n'est jamais exécuté

LegaDrift lit le code ; il n'exécute ni le code d'origine ni le code produit par un moteur de conversion.

Vos données

Elles ne transitent pas par LegaDrift

Pas d'accès à la production

LegaDrift n'extrait rien de votre production et n'y agit jamais. Il produit les paramétrages, vos équipes les installent.

Les données de production restent chez vous

Pour la migration des données, LegaDrift prépare les travaux et les configurations ; vos données ne passent pas par lui.

Pseudonymisation par défaut

Les identifiants de personnes sont pseudonymisés par défaut dans tout ce qui sort de votre périmètre et dans les données d'exécution que vous déposez.

Durée de conservation

Fixée projet par projet, jamais illimitée par défaut. Un conflit entre conservation et effacement est affiché, pas masqué.

Les accès

Chacun son rôle, chaque geste tracé

Projets cloisonnés

Chaque projet est isolé. Aucun accès n'existe en dehors d'un projet.

Rôles nommés

Administrateur, analyste, valideur et les autres rôles du projet sont attribués à des personnes nommées, avec des permissions distinctes.

Contrôle à quatre yeux

La validation d'un livrable par la personne qui l'a produit est signalée, et une dérogation est tracée.

Agents et outils tiers

Un agent d'IA ou un outil n'accède au projet qu'avec un jeton nominatif, limité à une portée, révocable, et ses lectures sont journalisées.

La traçabilité

Ce qui a été décidé, par qui et quand

Un journal vérifiable

Chaque geste est inscrit dans un journal chaîné. Un auditeur peut en vérifier l'intégrité avec des outils standards, sans accès au produit.

Valider, puis figer

Un livrable validé puis figé est verrouillé dans l'application. Seuls l'effacement de données personnelles et la suppression du projet peuvent encore le toucher, et ces actes sont tracés.

Les choix du projet consignés

Infrastructure, modèle d'IA, fournisseur, durée de conservation : chaque choix est enregistré avec sa date et son auteur.

Exports pour vos audits

Le journal, les choix du projet et les livrables figés s'exportent pour l'examen de vos équipes de sécurité et de vos auditeurs.

Ce que nous ne prétendons pas. LegaDrift ne détient aujourd'hui aucune certification de sécurité. Nous ne présentons pas le produit comme une garantie réglementaire : nous vous donnons les éléments précis pour que vos équipes jugent par elles-mêmes, et nous répondons à leurs questionnaires.
